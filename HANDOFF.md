## Squarespace Basics

### Accessing the Editor

1. Go to squarespace.com
2. Log in with your 8TPS account credentials
3. Click on your site name
4. Click "Edit" to enter the editor

### Page Structure

Each page in Squarespace is made of **sections** and **blocks**:
- **Sections**: Full-width containers (headers, content areas, footers)
- **Blocks**: Content units (text, images, buttons, forms, etc.)

### Editing Content

1. Click on any text to edit directly
2. Click images to replace/resize
3. Drag blocks to reorder
4. Use the + button to add new blocks

## Updating the Featured Production

When switching from one production to another (e.g., p h o r i a → Queer History Mixtape):

### Step 1: Move Current to Past Productions (when that section exists)
1. Copy the current production section
2. Paste into Past Productions page
3. Adjust styling as needed

### Step 2: Update Featured Section
1. Navigate to Home page
2. Find the Featured Production section
3. Update:
   - Production title
   - Description/synopsis
   - Production image
   - Ticket link
   - Dates

### Step 3: Save and Publish
1. Click "Save" in the editor
2. Review the preview
3. Click "Publish" when ready

## Adding New Content

### Adding a Photo to Media Gallery
1. Go to Media page
2. Click on the gallery block
3. Click "+" to add images
4. Upload from computer or drag and drop
5. Add captions and alt text (for accessibility)
6. Save and publish

### Adding a Video
1. Go to Media page
2. Add a "Video" block
3. Paste YouTube URL
4. Adjust size/layout as needed
5. Save and publish

### Adding a Pull Quote
1. Go to Home page
2. Find the quotes carousel section
3. Edit the carousel block
4. Add new slide with quote text and attribution
5. Save and publish

## Managing Forms

### Contact Form Submissions
1. Go to Squarespace dashboard
2. Click "Form & Survey Responses"
3. View, export, or manage submissions
4. Set up email notifications in Form settings

### Newsletter Signups
1. If using Squarespace Email Campaigns:
   - Go to Marketing → Email Campaigns
   - View subscriber list
2. If using external service (Mailchimp, etc.):
   - Check that service's dashboard

## SEO & Settings

### Page Titles & Descriptions
1. Click the gear icon on any page
2. Go to "SEO" tab
3. Set:
   - SEO Title (what shows in browser tab and Google)
   - SEO Description (what shows in search results)

### Social Sharing Images
1. In page settings → Social Image
2. Upload an image (1200x630px recommended)
3. This appears when page is shared on social media

## Troubleshooting

### Something looks broken
1. Try refreshing the page
2. Clear browser cache (Cmd+Shift+R)
3. Check if it's a saved draft vs. published

### Need to undo changes
1. Squarespace has version history
2. Go to Settings → Site Availability → Site History
3. Restore previous version if needed

### Domain issues
- Check DNS settings at domain registrar
- Verify Squarespace connection in Settings → Domains
