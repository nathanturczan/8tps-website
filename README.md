# 8TPS Website

Squarespace website project for **8TPS**, a radical vocal collective of trans, nonbinary, and gender-expansive musicians in Los Angeles.

**Client contacts:** Tanner Pfeiffer (pfeiffertanner6@gmail.com), Socks Whitmore
**Developer:** Nathan Turczan

---

## The Important Thing

**This is NOT a coded website.** The site is built and hosted on Squarespace so the client can edit everything themselves (swap productions, add photos, update quotes) without a developer. This repo is the working folder: planning docs, brand assets, and copy that get loaded *into* Squarespace. There is no build step and nothing to deploy.

## Brand Quick Reference

From `assets/epk/8TPS Style Guide 2026.pdf`:

- **Colors:** `#F14EEA` magenta · `#55C6FE` sky blue · `#5D54ED` indigo · `#411CB8` deep purple · pastel trans-flag stripes as background motif
- **Fonts:** Sailors (titles) · Flatory Sans (subtitles) · Inclusive Sans (body — available on Google Fonts)
- **Logos:** cassette icon in 3 variants (bottom text / inner text / no text) — usage rules in `DESIGN.md`
- **Tagline:** Community. Artistry. Joy. Trans Excellence.

## Design Direction

Client's #1 reference (from their Are.na board "8TPS Website Inspo"): **Roomful of Teeth** — large header photo, pull quote carousel, multi-part About section. Full 11-site breakdown with captions in `DESIGN.md`.

Hard constraints: body text visible without scrolling, minimal nav, no popups, no fade-in/animation effects, high contrast (full list in `SCOPE.md` / `DESIGN.md`).
